# Test Dashboard

Welcome to the Test Dashboard project! This is a dashboard application for testing and monitoring.

## About

Test Dashboard is a project designed to provide insights and analytics through an interactive web interface.

## Features

- Interactive dashboards
- Real-time monitoring
- Data visualization

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
git clone https://github.com/ksc-ai/Test-dashboard.git
cd Test-dashboard
npm install
```

### Running the Project

```bash
npm start
```

The application will be available at `http://localhost:3000`
